# Student Database

## Overview

A small relational database project for practicing table creation, data retrieval, filtering, aggregation, and SQL joins.

## Problem

Student records need a structured format so questions about students, courses, and performance can be answered consistently.

## Tools Used

- MySQL
- `student_database.sql`
- `student_queries_lesson2.sql`

## Files

- `student_database.sql` - schema and sample data for the student database.
- `student_queries_lesson2.sql` - example queries used in lesson 2 (filters and basic joins).
- `student_summary_queries_lesson3.sql` - summary and aggregate queries for lesson 3 (grouping, totals, averages).
- `join_exercise_lesson4.sql` - exercises focused on JOINs across the student-related tables.

## Process

1. Create the database and related tables.
2. Load sample student data.
3. Query the data with filters and calculations.
4. Use joins to answer questions across related tables.
5. Review query results for accuracy.

## Skills Practiced

- Relational database design
- SELECT statements and filters
- Aggregate functions
- Joins and business questions
