# Student Database

## Overview

A small relational database project for practicing table creation, database design, data retrieval, filtering, aggregation, joins, subqueries, updates, and constraint enforcement.

## Problem

Student records need a structured format so questions about students, courses, performance, and database integrity can be answered consistently and reliably.

## Tools Used

- MySQL
- MySQL Workbench
- `student_database.sql`
- `student_queries_lesson2.sql`
- `studentdb_normalization.mwb`

## Files

- `student_database.sql` - schema and sample data for the student database.
- `database_design_lesson7.sql` - database design and relationship planning for the project.
- `student_queries_lesson2.sql` - example queries used in lesson 2 (filters and basic joins).
- `student_summary_queries_lesson3.sql` - summary and aggregate queries for lesson 3 (grouping, totals, averages).
- `join_exercise_lesson4.sql` - exercises focused on JOINs across the student-related tables.
- `student_subqueries_cte_lesson5.sql` - practice with nested queries and CTE-based reporting.
- `student_modification_lesson6.sql` - insert, update, and delete tasks to maintain the database.
- `database_constraints_lesson8.sql` - rules that enforce valid data relationships and integrity.
- `studentdb_normalization.mwb` - a MySQL Workbench model of the normalized database structure.

## Process

1. Design the database structure and define table relationships.
2. Normalize the schema to reduce redundancy and improve consistency.
3. Load sample student data into the tables.
4. Query the data with filters, calculations, and aggregate functions.
5. Use joins, subqueries, and CTEs to answer business questions.
6. Update records carefully and enforce constraints to protect data quality.
7. Review query and modification results for accuracy.

## Skills Practiced
