# MySQL Projects

This folder contains relational database design and SQL practice exercises for building, querying, modifying, and validating small database projects.

## Study-plan target

Translate a business question into a correct SQL query and explain the tables, joins, filters, calculations, and data rules involved.

## Projects

- [Student Database](student-database/README.md) - design, query, normalize, and enforce rules for a small student database.

## Student-database files

- `student_database.sql` - schema and sample data for the student database.
- `database_design_lesson7.sql` - database design and table relationship planning.
- `student_queries_lesson2.sql` - example queries for lesson 2 (filters and basic joins).
- `student_summary_queries_lesson3.sql` - summary and aggregate queries for lesson 3 (grouping, totals, averages).
- `join_exercise_lesson4.sql` - JOIN-focused exercises across the student-related tables.
- `student_subqueries_cte_lesson5.sql` - subqueries and CTE-based analysis for complex questions.
- `student_modification_lesson6.sql` - data updates, inserts, and record maintenance tasks.
- `database_constraints_lesson8.sql` - primary keys, foreign keys, unique constraints, and validation rules.
- `studentdb_normalization.mwb` - MySQL Workbench model showing the normalized student schema.

## Skills practiced

- Creating databases and tables
- Designing normalized relational schemas
- Inserting, updating, and deleting records
- Filtering and aggregating data
- Joining related tables
- Writing subqueries and CTEs
- Enforcing database constraints and data integrity
- Turning business questions into SQL

Future practice can include the official Sakila sample database and more advanced reporting tasks.
