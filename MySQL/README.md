# MySQL Projects

This folder contains relational database and SQL practice.

## Study-plan target

Translate a business question into a correct SQL query and explain the tables, joins, filters, and calculations used.

## Projects

- [Student Database](student-database/README.md) - create and query a small student database

## Student-database files

- `student_database.sql` - schema and sample data for the student database (located in `student-database/`).
- `student_queries_lesson2.sql` - example queries for lesson 2 (filters and basic joins).
- `student_summary_queries_lesson3.sql` - summary and aggregate queries for lesson 3 (grouping, totals, averages).
- `join_exercise_lesson4.sql` - JOIN-focused exercises across the student-related tables.

## Skills practiced

- Creating databases and tables
- Inserting and retrieving data
- Filtering and aggregating records
- Joining related tables
- Turning business questions into SQL

Future practice can include the official Sakila sample database.
