# Student Analytics Report

## Overview

This project explores student academic performance through a Power BI report. It uses Excel and CSV data sources to build a data model, calculate measures with DAX, and create interactive visuals for analysis.

## What is included

- `student_analytics_data.xlsx` - original student performance dataset
- `student_analytics_data_2.csv` - alternate dataset for testing and comparison
- `Equipment_Inventory_Star_Schema.xlsx` - example data model diagram for a star schema
- Multiple Power BI report files:
  - `student_analytics_report.pbix`
  - `student_analytics_report_2.pbix`
  - `student_analytics_report_lesson3.pbix`
  - `student_analytics_report_lesson4.pbix`

## Problem Statement

Student performance information becomes more actionable when it is modeled, filtered by relevant dimensions, and summarized as clear insights for decision-making.

## Tools Used

- Microsoft Power BI Desktop
- Excel and CSV source data files
- DAX for measures and calculations
- Interactive report pages and slicers

## Process

1. Inspect and clean the source data.
2. Load data into Power BI and establish relationships.
3. Build measures for performance metrics and comparisons.
4. Design report pages with filters, visuals, and interactions.
5. Review results and document the main insights.

## Skills Practiced

- Data preparation and modeling in Power BI
- DAX measure creation and analysis
- Report and dashboard design
- Communicating findings with visuals
