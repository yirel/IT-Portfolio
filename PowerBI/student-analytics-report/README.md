# Student Analytics Report

Updated: August 13, 2026

## Overview

This project explores student academic performance through a Power BI report. It demonstrates building a data model, calculating metrics with DAX, and designing interactive visuals for analysis. The folder includes multiple report versions showing progression through key Power BI and DAX concepts.

## Files

**Data Sources:**
- `student_analytics_data.xlsx` — original student performance dataset
- `student_analytics_data_2.csv` — alternate dataset for testing and comparison
- `Equipment_Inventory_Star_Schema.xlsx` — example star schema data model reference

**Report Files (progression through lessons):**
- `student_analytics_report.pbix` — initial report
- `student_analytics_report_2.pbix` — second version
- `student_analytics_report_lesson3.pbix` — lesson 3 version
- `student_analytics_report_lesson4.pbix` — lesson 4 version
- `student_analytics_report_lesson5.pbix` — lesson 5 version
- `student_analytics_report_lesson6.pbix` — lesson 6 version

## Problem Statement

Student performance data becomes more actionable when it is properly modeled, filtered by relevant dimensions, and presented through clear, interactive visuals for decision-making.

## Tools Used

- Microsoft Power BI Desktop
- Excel and CSV source data files
- DAX (Data Analysis Expressions) for measures and calculations
- Interactive report pages with slicers and filters

## Process

1. Inspect and clean source data for accuracy
2. Load data into Power BI and establish table relationships
3. Build a relational data model
4. Create DAX measures for performance metrics and key calculations
5. Design interactive report pages with visuals and filters
6. Refine reports through iteration and feedback
7. Document insights and findings

## Skills Practiced

- Data preparation and validation
- Data modeling and relationships in Power BI
- DAX functions for aggregations and calculations
- Report design with interactive elements
- Visual communication of analytical findings
