# Student Analytics Report

## Overview

A Power BI report project that uses student data to explore academic performance and communicate findings through interactive visuals.

## Problem

Student performance data is more useful when it can be explored by relevant dimensions and summarized into clear findings for decision-making.

## Tools Used

- Microsoft Power BI
- Excel and CSV source data
- DAX measures and interactive report pages

## Process

1. Inspect and prepare the source data.
2. Load the data into Power BI and define the model.
3. Create measures and visuals for key performance questions.
4. Check filters, relationships, and report interactions.
5. Summarize findings and recommendations.

## Skills Practiced

- Data preparation and modeling
- DAX fundamentals
- Dashboard design
- Presenting useful recommendations
