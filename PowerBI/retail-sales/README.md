# Retail Sales Dashboard

## Overview

This project uses Power BI to analyze retail sales performance and present the results in an interactive dashboard. It demonstrates how sales data can be transformed into useful business insights through data preparation, modeling, measures, and report design.

## Files

- `retail_sales.xlsx` - Excel source data for the retail sales analysis
- `retail_sales_dashboard_lesson7&8.pbix` - Power BI dashboard created for lessons 7 and 8

## Tools Used

- Microsoft Power BI Desktop
- Microsoft Excel
- DAX measures and calculated fields
- Interactive visuals, filters, and slicers

## Process

1. Review and prepare the retail sales source data
2. Load the data into Power BI
3. Create the data model and required calculations
4. Build visuals for sales performance analysis
5. Add filters and slicers for interactive exploration
6. Refine the dashboard layout and presentation

## Skills Practiced

- Importing and preparing Excel data in Power BI
- Building analytical data models
- Creating DAX calculations for sales metrics
- Designing interactive dashboards
- Communicating business performance through data visualization
