# Flexbox Practice

This project demonstrates CSS Flexbox layout techniques for organizing portfolio content.

## Overview

A responsive layout practice page that uses Flexbox to arrange a header navigation bar and a grid of skill cards in a clean, flexible manner.

## Features

- **Header Navigation** — Top navigation bar with portfolio links using Flexbox alignment
- **Card Container** — Multiple skill cards (Python, Excel, MySQL) arranged with Flexbox
- **Responsive Layout** — Flexible spacing and alignment that adapts to different screen sizes

## Skills Demonstrated

- CSS Flexbox (`display: flex`)
- Flex properties: `justify-content`, `align-items`, `flex-direction`
- Card-based layout design
- Semantic HTML structure
- Responsive navigation bars

## Files

- `index.html` — HTML structure with header navigation and skill cards
- `style.css` — Flexbox styling for layout and responsive design

## Learning Focus

- Understanding how Flexbox handles space distribution and alignment
- Creating flexible layouts that work across different viewport sizes
- Organizing content with flex containers and items
