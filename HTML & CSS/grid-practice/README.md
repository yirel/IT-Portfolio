# CSS Grid Practice

This project demonstrates CSS Grid layout techniques for building dashboard-style portfolio layouts.

## Overview

A data analytics dashboard practice page that uses CSS Grid to create a structured, multi-column layout showcasing various skills and projects.

## Features

- **Grid Container Layout** — Multi-column grid structure for organizing content sections
- **Featured Project Panel** — A prominent panel that spans multiple grid cells
- **Skill Panels** — Individual panels for different skill areas (Python, Excel, MySQL, Power BI)
- **Footer Section** — Positioned using grid layout

## Skills Demonstrated

- CSS Grid (`display: grid`)
- Grid properties: `grid-template-columns`, `grid-template-rows`, `grid-gap`
- Grid item spanning with `grid-column` and `grid-row`
- Named grid areas and positioning
- Responsive grid design

## Files

- `index.html` — HTML structure with header, grid container, and skill panels
- `style.css` — CSS Grid styling for dashboard layout

## Learning Focus

- Understanding CSS Grid for complex multi-column layouts
- Managing grid items and grid cells effectively
- Creating emphasis through spanning grid areas
- Building professional dashboard-style layouts
