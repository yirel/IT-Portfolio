# Responsive Practice

A responsive HTML and CSS practice page for presenting portfolio skills in a card-based layout.

## What it demonstrates

- Semantic page structure with a header and main content area
- CSS Grid for arranging skill cards in two columns
- A mobile breakpoint that changes the layout to one column
- Responsive spacing and sizing for smaller screens

## Files

- `index.html` — portfolio skills page
- `style.css` — grid layout, card styling, and responsive rules

## How to view

Open `index.html` in a browser and resize the viewport to see the layout switch from two columns to one.
