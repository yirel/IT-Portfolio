# System Design Practice

A design system practice page for exploring consistent typography, spacing, color, cards, and button styling with HTML and CSS.

## What it demonstrates

- CSS custom properties for shared design values
- Consistent typography using rem-based sizing
- Reusable spacing, card, and color styles
- Responsive card layout with CSS Grid
- A styled call-to-action button with a hover state

## Files

- `index.html` — design system examples and sample content
- `style.css` — design tokens, component styles, and layout rules

## How to view

Open `index.html` in a browser to review the design examples and interact with the call-to-action button.
