# Accessible Project Page

Updated: August 8, 2026

## Overview

This project focuses on building an accessible and visually clear project page for my learning portfolio. It combines HTML structure, CSS styling, images, tables, and a contact form.

## Files

- `index.html` — main page structure and content
- `style.css` — styling for layout, colors, tables, forms, and buttons
- `profile.jpg` and `workspace.jpg` — supporting images for the page

## Features

- Clear page sections for introduction, project summary, skills, lessons, and contact details
- Styled cards for grouped content
- Accessible form labels and descriptive image alt text
- Consistent colors and spacing for a polished presentation

## Skills Practiced

- HTML page layout with sections and semantic content
- CSS styling for cards, tables, forms, and buttons
- Accessibility basics, including labels and alt text
- Designing a professional portfolio page
