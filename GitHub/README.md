# GitHub Projects

This folder is for GitHub workflow practice and portfolio documentation.

## Study-plan target

A recruiter should be able to understand what was built, why it was built, which tools were used, and what results were found.

## Workflow practiced

- Repositories and local project organization
- Commits with clear messages
- Branches and pull requests
- Merging and maintaining project history
- README files that explain the problem, process, results, and lessons learned

The category READMEs in this repository are part of that documentation practice.

## Portfolio site

The [Portfolio Site](portfolio-site/) folder contains the GitHub Pages site for showcasing larger, completed portfolio projects. It is also the starter website for the broader IT portfolio.
