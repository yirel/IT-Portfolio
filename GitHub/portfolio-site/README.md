# IT Portfolio Starter

A beginner-friendly portfolio website for showcasing projects in:

- Python
- Excel
- MySQL
- Power BI
- GitHub
- HTML and CSS

## Main project goal

Build one central website where you can:

1. Introduce yourself.
2. Present your technical skills.
3. Display completed projects.
4. explain how you solved each problem.
5. Link to GitHub repositories and downloadable work.
6. document your growth as an IT student.

## First setup steps

1. Open `index.html` in a browser.
2. Replace the sample email, GitHub, and LinkedIn links.
3. Edit the About Me section.
4. Create a GitHub repository named `it-portfolio`.
5. Upload these files.
6. Enable GitHub Pages from the repository settings.
7. Add the live portfolio link to your GitHub profile.

## How to add a project

Copy one project card inside `index.html`, then update:

- Project title
- Short problem description
- Tools used
- Live demo link
- Source-code link
- Category: `data`, `database`, or `web`

Use `PROJECT_TEMPLATE.md` to document the full case study.

## Recommended learning-to-portfolio workflow

For each lesson:

1. **Recall:** Review the concept.
2. **Practice:** Finish a small exercise.
3. **Save:** Keep the files in the correct subject folder.
4. **Document:** Write what you learned.
5. **Commit:** Upload the work to GitHub.
6. **Showcase:** Add strong projects to the website.

## Suggested first six mini-projects

| Subject | Mini-project |
|---|---|
| Python | Student grade calculator and report |
| Excel | Personal expense or sales dashboard |
| MySQL | School enrollment database |
| Power BI | Student or sales performance dashboard |
| GitHub | Well-documented learning repository |
| HTML/CSS | This responsive portfolio website |

## When a project is portfolio-ready

A project should include:

- A clear problem or goal
- The dataset or input used
- A description of your process
- Screenshots or a live preview
- Important code or formulas
- Results and insights
- Challenges and lessons learned
- A working repository link

## Important edits before publishing

Search the files for these placeholders:

- `your-email@example.com`
- `https://github.com/`
- `https://www.linkedin.com/`
- Links containing only `#`

Replace them with your real information and project links.
