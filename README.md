# IT Portfolio

This repository contains my learning projects in:

- Python
- Excel
- MySQL
- Power BI
- GitHub
- HTML and CSS

## Purpose

To build job-ready IT and data analytics skills through practical projects.

## Repository Organization & Privacy

This repository is **organized and privacy-safe**:

- **Clean structure**: All files are organized by subject area (Python, Excel, MySQL, Power BI, etc.) with clear documentation
- **Security best practices**: 
  - A comprehensive `.gitignore` prevents accidental commits of temporary files, logs, and sensitive data
  - A `.env.example` file shows the structure needed for configuration without exposing secrets
  - No passwords, API keys, or sensitive credentials are stored in version control
- **No temporary files**: Output folders, test runs, and temporary data files have been removed
- **Production-ready**: The repository follows best practices for version control and is ready for sharing

## Study Plan

The portfolio follows a flexible 12-week study plan with one main subject each weekday:

| Day | Subject | Practical focus |
| --- | --- | --- |
| Monday | Python | Clean, analyze, visualize, and explain data |
| Tuesday | Excel | Transform business records into manager-ready reports |
| Wednesday | MySQL | Translate business questions into SQL queries |
| Thursday | Power BI | Build models, DAX measures, and interactive dashboards |
| Friday | GitHub | Explain what was built, why it matters, and what was learned |
| Saturday | HTML & CSS | Present projects through a responsive portfolio |
| Sunday | Integration | Review, connect subjects, and improve documentation |

## Portfolio Workflow

Each project should document:

1. The problem and objectives
2. Tools and data sources
3. Preparation and implementation steps
4. Testing, results, and key insights
5. Challenges, lessons learned, and next steps

## Assessments and Capstone

- **Week 4:** Build a Python program, Excel summary, SQL queries, Power BI report, GitHub documentation, and simple HTML page.
- **Week 8:** Analyze one dataset across Python or Power Query, MySQL, Excel, Power BI, GitHub, and the portfolio website.
- **Week 12:** Complete an integrated business performance analysis with findings, recommendations, and limitations.
