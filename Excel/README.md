# Excel Projects

This folder contains spreadsheet projects for transforming raw records into reports that a manager can understand without examining the source data.

## Study-plan target

Build accurate, refreshable reports using formulas, data preparation, PivotTables, and clear presentation.

## Projects

- [Conditional Calculations](conditional-calculations/README.md) - master conditional formulas and dynamic calculations
- [Equipment Inventory](equipment-inventory/README.md) - organize equipment records and build clear inventory summaries
- [Lookup Functions](lookup-functions/README.md) - practice Excel lookup and reference formulas with workbook examples
- [Pivot Data - Sales](pivot-data-sales/README.md) - create and analyze pivot tables for sales data summarization
- [Power Query Practice](power-query-practice/README.md) - automate data transformation and preparation workflows
- [Sales Dashboard](sales-dashboard/README.md) - design interactive dashboards for sales performance analysis
- [Text and Dates](text-and-dates/README.md) - explore text manipulation and date functions for cleaning and organizing data

## Skills practiced

- Data entry and cleaning
- Formulas and structured tables
- Lookup and reference functions
- Text and date manipulation
- PivotTables and summary reporting
- Communicating business information visually

Private or sensitive data should not be published in this folder.
