# Lookup Functions

## Objective

Learn and practice Excel's lookup functions for finding and retrieving data from tables.

## Skills Practiced

- VLOOKUP for vertical lookups
- HLOOKUP for horizontal lookups
- INDEX/MATCH combinations for flexible lookups
- XLOOKUP (Excel 365) for advanced lookups
- Error handling with IFERROR and IFNA

## Files in This Project

- Practice worksheets with lookup function exercises
- Sample lookup tables and reference data
- Real-world business scenarios

## Key Takeaways

Lookup functions are essential for working with large datasets, enabling quick data retrieval and cross-referencing without manual searching.

## Next Steps

- Master INDEX/MATCH for more flexible lookups
- Combine lookups with conditional logic
- Apply to data analysis and reporting tasks
