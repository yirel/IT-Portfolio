# Text and Dates

## Objective

Master Excel's text and date functions for cleaning, formatting, and manipulating text and time-based data.

## Skills Practiced

- Text functions (LEFT, RIGHT, MID, LEN, CONCATENATE, TEXTJOIN)
- Case conversion (UPPER, LOWER, PROPER)
- Text search and replace (FIND, SEARCH, SUBSTITUTE)
- Date functions (TODAY, DATE, DATEVALUE, DATEDIF)
- Time calculations and formatting
- Data cleaning with text functions

## Files in This Project

- Practice worksheets with text and date exercises
- Real-world data cleaning scenarios
- Formatting examples

## Key Takeaways

Text and date functions are critical for data cleaning and preparation. Most real-world datasets require manipulation of text and dates before analysis, making these skills essential for data professionals.

## Common Use Cases

- Cleaning customer names and addresses
- Extracting information from unstructured text
- Calculating age or tenure from dates
- Formatting dates for reporting
- Concatenating data fields for unique identifiers
