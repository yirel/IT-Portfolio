# Equipment Inventory

## Overview

A spreadsheet project for organizing equipment inventory records and practicing clear operational reporting.

## Problem

Equipment records are easier to manage when items, categories, and status information are stored consistently and can be summarized quickly.

## Tools Used

- Microsoft Excel
- Formulas and worksheet tables
- Inventory workbook files in this folder

## Process

1. Review and organize the inventory fields.
2. Apply consistent formatting and spreadsheet structure.
3. Use formulas or summaries to make the records easier to review.
4. Check the workbook for accuracy and readability.

## Skills Practiced

- Data organization and cleaning
- Spreadsheet formulas
- Business reporting
- Quality checking

## Next Steps

Add a PivotTable or dashboard view with inventory counts by category, status, or location, then document measurable findings.
