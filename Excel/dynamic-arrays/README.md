# Dynamic Arrays

An Excel spreadsheet demonstrating dynamic array formulas and functions in modern Excel.

## What it covers

Dynamic arrays are a powerful Excel feature that allow formulas to return multiple values and automatically spill across cells. This workbook practices:

- FILTER function to extract rows based on criteria
- SORT function to arrange data by specified columns
- UNIQUE function to identify distinct values
- Array operations and spilling behavior
- Combining dynamic arrays with other functions
- Practical applications for data analysis and reporting

## Files

- `dynamic_arrays.xlsx` — Excel workbook with dynamic array formula examples and exercises

## How to use

1. Open `dynamic_arrays.xlsx` in Excel (Office 365 or Excel 2021+)
2. Review each sheet to see different dynamic array applications
3. Modify criteria and formulas to explore how arrays automatically adjust
4. Experiment with combining FILTER, SORT, and UNIQUE functions

## Skills practiced

- Dynamic array formulas and spilling
- Array-based data filtering and sorting
- Formula construction and troubleshooting
- Data transformation without helper columns
- Modern Excel functions (Office 365+)
