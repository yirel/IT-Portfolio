# Power Query Practice

## Objective

Learn and practice Power Query for data transformation, cleaning, and preparation without manual formulas.

## Skills Practiced

- Loading data from multiple sources
- Removing and transforming columns
- Filtering and sorting data
- Merging and appending queries
- Combining data from multiple files
- Creating reusable data transformation workflows
- Automating data refresh processes

## Files in This Project

- `customer_lookup.xlsx` - Customer reference data
- `product_lookup.xlsx` - Product reference data
- `sales_january.xlsx` - January sales transactions
- `sales_february.xlsx` - February sales transactions
- `power_query.xlsx` - Main workbook with Power Query transformations

## Key Takeaways

Power Query enables efficient data preparation by automating repetitive transformation tasks, reducing manual work and improving data consistency across multiple sources.

## Process

1. Load source data from multiple Excel files
2. Apply transformations (removing duplicates, standardizing formats, etc.)
3. Merge customer and product lookup tables with sales data
4. Create a consolidated dataset for analysis
5. Set up refresh to automatically update when source files change

## Next Steps

- Combine Power Query with pivot tables for automated reporting
- Create advanced transformations with custom functions
- Connect to external data sources (databases, web services)
- Build refresh schedules for regular data updates
