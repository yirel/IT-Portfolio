# NumPy Fundamentals

This project demonstrates fundamental NumPy operations for numerical computing in Python.

## Purpose

The script covers basic NumPy array operations, statistical calculations, and practical applications using arrays.

## What it does

- Creates and manipulates NumPy arrays
- Performs basic arithmetic operations on arrays
- Calculates totals, averages, minimums, and maximums
- Applies array indexing and slicing techniques
- Implements boolean indexing for filtering data
- Computes percentage changes and differences
- Analyzes transaction data using array operations

## Files

- `numpy_fundamentals.py` — main script with NumPy examples and exercises

## Key Concepts Covered

- **Array Creation**: Creating NumPy arrays from lists
- **Arithmetic Operations**: Adding, subtracting, multiplying, and dividing arrays
- **Statistical Functions**:
  - `np.sum()` — adds all values
  - `np.mean()` — finds the average
  - `np.min()` — finds the smallest value
  - `np.max()` — finds the largest value
- **Array Indexing and Slicing**: Accessing specific elements and ranges
- **Boolean Indexing**: Filtering arrays based on conditions
- **Practical Examples**: Working with quiz scores, activity scores, exam scores, and transaction analysis

## How to run

1. Open the folder in a Python editor or terminal.
2. Run the script with Python: `python numpy_fundamentals.py`
3. Observe the output showing calculations and analysis results.

## Skills practiced

- NumPy array creation and manipulation
- Vectorized operations on arrays
- Statistical analysis and calculations

- Performance comparison over list-based operations
