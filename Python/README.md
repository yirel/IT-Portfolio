# Python Projects

This folder contains Python practice projects that focus on programming fundamentals, algorithm development, and introductory data analysis.

## Learning Goals

- Build confidence with Python syntax, control flow, and functions.
- Practice reading user input and producing formatted program output.
- Apply basic data cleaning and analysis techniques in Python.
- Write clear project documentation and explain findings.

## Projects

- [csv-cleaner](csv-cleaner/) — clean and validate CSV data, separate valid and invalid rows, and generate error logs.
- [daily-transaction-summary](daily-transaction-summary/) — analyze and summarize daily transaction data with Python.
- [inventory-summary](inventory-summary/) — store and document inventory summary outputs for the exercise.
- [numpy-fundamentals](numpy-fundamentals/) — NumPy array operations, statistical calculations, and data analysis techniques.
- [pandas-fundamentals](pandas-fundamentals/) — Pandas DataFrames, data loading, filtering, sorting, and transformation exercises.
- [reusable-grade-tools](reusable-grade-tools/) — reusable grade calculation tools and helper functions.
- [student-grade](student-grade/) — student grade calculator, grade report generation, and classification examples.

## Folder structure

- `csv-cleaner/` — contains the CSV cleaning script plus input, cleaned, failed, and error log files.
- `daily-transaction-summary/` — contains `daily_transaction_summary.py` and example output files.
- `inventory-summary/` — contains the inventory summary output for the project.
- `numpy-fundamentals/` — contains the NumPy fundamentals script with array operations and statistical calculations.
- `pandas-fundamentals/` — contains the Pandas notebook with DataFrame operations and data analysis exercises.
- `reusable-grade-tools/` — contains reusable Python modules for grade calculations and utilities.
- `student-grade/` — contains student grade projects with calculators, reports, and examples.

## How to use this folder

1. Open the project folder you want to run.
2. Review the README or code comments for usage instructions.
3. Run the Python file in a terminal or code editor.
4. Experiment with sample input and modify the code to explore new ideas.

## Skills practiced

- Variables, conditions, loops, and functions
- Input/output handling and data formatting
- Basic data validation and processing
- Writing readable code and documenting results

## Notes

Each project should include a short description of the problem, objectives, tools used, process, testing approach, results, challenges, and lessons learned. This README is meant to help navigate the folder and understand the learning focus for each exercise.
