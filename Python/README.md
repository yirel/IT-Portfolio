# Python Projects

This folder contains Python practice focused on programming fundamentals and beginner data analysis.

## Study-plan target

By the end of the curriculum, I should be able to receive an unfamiliar CSV file, clean it, analyze it, visualize important findings, and explain my conclusions.

## Projects

- [Student Grade Calculator](Student%20Grade%20Calculator) - calculate grades from student input
- [Student Grade Report](Student%20Grade%20Report) - generate a student grade report

## Skills practiced

- Variables, conditions, loops, and functions
- Input and output
- Data cleaning and analysis
- Explaining results clearly

Each project should document its problem, objectives, tools, process, testing, results, challenges, and lessons learned.
