# Pandas Fundamentals

This project demonstrates fundamental Pandas operations for data manipulation and analysis in Python.

## Purpose

The Jupyter notebook covers essential Pandas techniques for working with tabular data, including DataFrame creation, loading data, filtering, sorting, and data transformation.

## What it does

- Creates DataFrames from dictionaries
- Loads and inspects CSV data
- Displays and examines data structure and statistics
- Selects specific columns and rows
- Filters data based on single and multiple conditions
- Sorts data by one or multiple columns
- Adds new columns with calculated values
- Applies transformations and classifications

## Files

- `pandas_fundamentals.ipynb` — Jupyter notebook with interactive Pandas examples
- `student_scores.csv` — sample student data used for exercises
- `cleaned_student_scores.csv` — processed output from data operations

## Key Concepts Covered

- **DataFrame Creation**: Creating DataFrames from dictionaries and CSV files
- **Data Inspection**:
  - `df.head()` — view first rows
  - `df.tail()` — view last rows
  - `df.info()` — display structure and types
  - `df.describe()` — show summary statistics
- **Column Selection**: Single and multiple column access
- **Row Filtering**:
  - Simple conditions (e.g., score >= 90)
  - Multiple conditions with boolean operators
  - Filtering by specific values
- **Sorting**: By single and multiple columns
- **Data Transformation**: Adding new columns with calculations and conditional logic

## How to run

1. Navigate to the folder in your terminal.
2. Start Jupyter: `jupyter notebook pandas_fundamentals.ipynb`
3. Run cells sequentially to see interactive outputs.
4. Modify code and re-run cells to explore different operations.
