# Daily Transaction Summary

This project practices basic Python programming with lists, loops, and simple calculations.

## Purpose

The script collects transaction values, calculates totals, averages, and identifies the highest and lowest transactions.

## What it does

- Stores transaction amounts in a list
- Adds values to calculate a running total
- Counts the number of transactions entered
- Finds the highest and lowest values
- Supports user input for transaction entry

## Files

- `daily_transaction_summary.py` — main script for the exercise
- `Example Run2` — sample output from a previous run

## How to run

1. Open the folder in a Python editor or terminal.
2. Run the script with Python.
3. Enter the number of transactions and their values.
4. Review the summary printed in the terminal.

## Skills practiced

- Lists and loops
- User input handling
- Conditional logic
- Basic reporting and formatting
