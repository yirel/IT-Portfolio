# Data Cleaning with Pandas

A Jupyter notebook demonstrating practical data cleaning techniques using Pandas on a messy sales dataset.

## What it covers

- Loading and inspecting data with `head()`, `info()`, and `describe()`
- Removing duplicate rows
- Handling missing values and null checks
- Converting data types (numeric and datetime)
- Cleaning and standardizing text labels
- Replacing inconsistent values with standard format
- Creating computed columns (Status, Profit Margin)
- Selecting and reordering columns
- Exporting cleaned data to a new CSV file

## Files

- `data_cleaning.ipynb` — Jupyter notebook with data cleaning exercises
- `messy_sales.csv` — sample input data with inconsistencies
- `cleaned_sales.csv` — output of cleaned and transformed data

## How to use

1. Start Jupyter: `jupyter notebook data_cleaning.ipynb`
2. Review each cell to see the data cleaning steps
3. Run cells individually or all at once to produce the cleaned output
4. Compare `messy_sales.csv` to `cleaned_sales.csv` to see the transformations

## Skills practiced

- Pandas DataFrame operations
- Data validation and standardization
- Text manipulation and formatting
- Data type conversions
- Feature engineering (new columns)
- CSV file I/O
