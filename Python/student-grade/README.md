# Student Grade

This project demonstrates a simple student grade calculator and report generator in Python.

## Purpose

The script collects student scores, calculates a final grade, classifies performance, and produces a result summary.

## Files

- `student_grade_classifier` — executable example or supporting file for the grade classification workflow
- `Student Grade Calculator` — example output or supporting file for the calculator
- `Student Grade Report` — example output or report file
- `Example Run` — sample run output

## What it does

- Accepts student name and score inputs
- Calculates a final grade from quiz, activity, and exam scores
- Classifies the student's performance level
- Determines whether the student passed or failed
- Produces a simple grade report

## How to run

1. Open the folder in a Python editor or terminal.
2. Run the relevant Python script for the grade calculator.
3. Enter the required student and score information.
4. Review the printed grade report or output files.

## Skills practiced

- User input handling
- Conditional logic
- Basic calculations
- Report generation and documentation
