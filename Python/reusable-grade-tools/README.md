# Reusable Grade Tools

This project contains reusable Python modules for grade calculations and performance classification.

## Purpose

The goal is to separate calculation logic into helper functions that can be reused across multiple programs.

## Files

- `calculator.py` — main entry point for the grade tool example
- `grade_tools.py` — grade calculation and classification logic
- `grade_tools2.py` — alternative or extended grade tool functions
- `math_tools.py` — mathematical helper functions
- `main.py` — small demo program that uses the grade tools

## How to run

1. Open the folder in a Python editor or terminal.
2. Run `main.py`.
3. Enter student information and scores when prompted.
4. Review the generated grade report.

## Skills practiced

- Modular programming
- Reusable functions
- Input validation
- Basic report generation
